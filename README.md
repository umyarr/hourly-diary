# Почасовой дневник для Telegram

Однопользовательский Telegram-бот для текстовых и голосовых записей. Он отправляет вопросы по расписанию, принимает свободные заметки в любое время, хранит исходное аудио и текст в SQLite и поддерживает выгрузку записей.

## Возможности

- Список владельцев задаётся через `OWNER_ID`; случайные пользователи не регистрируются.
- Расписание и часовой пояс настраиваются через переменные окружения.
- Голосовые записи сохраняются. Распознавание можно включить через поддерживаемого STT-провайдера.
- Исправления транскрипта сохраняют историю версий.
- `/today` и `/export` готовят архив с Markdown, JSON и доступными аудиофайлами.
- `/sync` создаёт явный запрос на синхронизацию с Obsidian. Локальный клиент запускает `sync-poll` вручную; без запроса команда возвращает `idle` и не скачивает данные.
- SQLite использует WAL, а резервные копии создаются отдельно от синхронизации.

## Запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install --no-deps .
```

Задай переменные окружения для процесса или службы. `.env.example` — только пример: приложение не загружает `.env` автоматически.

Основные параметры:

- `BOT_TOKEN` и `OWNER_ID` — обязательные значения.
- `CHAT_ID` — необязательный личный чат владельца для напоминаний до `/start`.
- `DATA_DIR` — каталог базы и аудиофайлов.
- `TIMEZONE` — часовой пояс расписания.
- `STT_PROVIDER`, `STT_API_KEY`, `STT_MODEL` — настройки распознавания; по умолчанию распознавание выключено.

Запуск бота:

```text
python -m hourly_diary run
```

## Команды

- `/start` — начать дневник.
- `/today` — записи за сегодня.
- `/export` — показать формат выгрузки; поддерживаются день и диапазон дат.
- `/sync` — поставить запрос на синхронизацию с Obsidian.
- `/status` — состояние дневника и последней синхронизации.
- `/pause` и `/resume` — управлять напоминаниями; свободные заметки принимаются и на паузе.
- `/correct` — исправить транскрипт ответом на голосовую запись.

## Ручная синхронизация с Obsidian

После `/sync` запусти на компьютере, где доступно хранилище Obsidian:

```text
python -m hourly_diary sync-poll --host <ssh-alias> --port 8443 --vault <path-to-vault>
```

Команда забирает только явно запрошенный snapshot. Настраивать периодический опрос не требуется. SSH-профиль и доступ к серверу настраиваются отдельно.
